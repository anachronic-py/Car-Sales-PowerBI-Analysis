🚗 Car Sales Executive Dashboard

📌 Project Overview
This project transforms raw dealership data into a high-impact executive "Cockpit." The goal was to track $89M in revenue and identify performance trends across regions.

📊 Key Features
Interactive Slicers: Dynamic filtering by Region, Company, and Body Style.

Top-N Analysis: Automatically identifies the #1 Dealer based on Sales Price without using complex code.

KPI Cards: Instant visibility into Total Revenue, Dealer Count, and Average Customer Income.

Gender Demographics: Visual breakdown showing a ~79% male customer base.

🎨 Design Choices
Theme: High-contrast Dark Mode for executive readability.

Color Palette: Used Yellow (#F2C80F) for focus metrics and Traffic Light colors (Green/Red) for performance ranking.

🛠️ Tools Used
Power BI Desktop

Power Query (Data Cleaning)

Top-N Filtering Logic
